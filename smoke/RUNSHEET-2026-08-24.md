## SMOKE 4 — Painter PH2, the six multi-paint kinds

**Judge this one in `jas_dioxus`** — PH2 is the Rust painter conversion
(`jas_dioxus/src/painter/element_render.rs`).

    cd jas_dioxus && dx serve
    # then open smoke/03-painter-ph2.svg

The scene holds one **convertible** instance of each of the six kinds PH2
converted — Rect · Circle · Ellipse · Polygon · Polyline · Path — each with a
plain solid fill and a plain solid centre-aligned stroke, so **every one is drawn
by the NEW path.** That arm has never been looked at.

**PASS:** all six render as they did before the painter conversion —

| look at | PASS |
|---|---|
| fill and stroke together | fill under stroke, no doubled edge, no gap between them |
| stroke placement | centred on the outline, not inside or outside it |
| where fill meets stroke | no alpha shift or dark seam — the two paints compose as one |
| the open polyline (5) | stroked only, no phantom fill closing it |
| the closed path (6) | closes cleanly at the `Z` |

**Worth knowing while you look:** PH2 routes to the new seam **only** when the
paint is display-list-equivalent to the legacy body; anything it cannot reproduce
exactly (set stroke brush, variable width, arrowheads, anchor-aligned dashing
that expands into sub-paths, inside/outside on an ellipse arc, freeform
gradients) **falls back to the legacy arm**. The scene deliberately contains none
of those, so what you are judging is the converted path alone. If you want the
fallback arm too, drawing any shape with a gradient exercises it.
